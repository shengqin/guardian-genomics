# Guardian Genomics: Website

Source for the Guardian Genomics website, live at **[shengqin.github.io/guardian-genomics](https://shengqin.github.io/guardian-genomics/)**.

Guardian Genomics is developing genetics-guided cell-free RNA blood tests, starting with **CardioGuardian** for coronary artery disease risk. The approach builds on a plasma cell-free RNA signature that predicts disease onset (provisional patent).

A single-page static site (`index.html`) deployed with GitHub Pages.
